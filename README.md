# J&P Gourmet — site demonstrativo

Site responsivo para apresentar sabores de pipoca gourmet e montar pedidos para envio pelo WhatsApp.

## Estrutura
- `index.html`: página principal, catálogo, pedido e contato.
- `css/style.css`: identidade visual em marrom, creme e dourado, animações leves e layout responsivo.
- `js/app.js`: catálogo, tamanhos, preços dinâmicos, carrinho e mensagem de pedido via WhatsApp.

## Antes de publicar
Adicionar as fotos e a logo originais na pasta `assets/img/` com os nomes usados no código. Confirmar o preço de Nutella antes de habilitar pedidos desse sabor.
